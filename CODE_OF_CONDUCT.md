# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be direct, be kind, assume good faith. Harassment or personal attacks are not tolerated. Maintainers may remove comments, commits, or contributors that violate these standards.

Report concerns to the maintainers via a private GitHub message or the repository's security advisory channel.
